# 🎮 Игра "Угадай число" (Два режима + Умный ИИ)

Интерактивная консольная игра на Python, созданная для демонстрации работы алгоритма бинарного поиска и обработки пользовательского ввода.

## ✨ Фичи проекта
* **Два режима игры**: можно угадывать самому, а можно заставить компьютер искать твое загаданное число.
* **4 уровня сложности** для игрока: от Легкого (1-10) до Невозможного (1-1000).
* **Умный ИИ**: режим компьютера работает на алгоритме **Бинарного поиска (Binary Search)**, отсекая половину вариантов за каждый шаг.
* **Анти-чит система**: ИИ выдаст ошибку, если игрок начнет врать в показаниях "больше/меньше".
* **Краш-тест (`try-except`)**: игра защищена от дурака — код не упадет с ошибкой, если вместо цифры ввести текст.

## 🕹 Инструкция по запуску
Для работы игры нужен установленный Python 3.x.

Запустите файл через терминал или консоль:
```bash
python game1.py
```
